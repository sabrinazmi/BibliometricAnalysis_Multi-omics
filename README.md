# Recent Trends on Multi-omics Studies in Cancer Research: A Bibliometric Study

This repository contains data and code for the bibliometric analysis of multi-omics studies in cancer research, as published in the *International Journal of Innovative Computing*.

## 📄 Paper Information  
- **Title**: Recent Trends on Multi-omics Studies in Cancer Research: A Bibliometric Study  
- **Journal**: *International Journal of Innovative Computing*  
- **Authors**: Nur Sabrina Azmi & Weng Howe Chan  
- **DOI**: https://doi.org/10.11113/ijic.v15n2.540
